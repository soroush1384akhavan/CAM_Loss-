# روند تغییرات پروژه (Project States)

این پوشه «دفتر وضعیت» پروژه است. هر بار که تغییر مهمی اتفاق می‌افتد، یک فایل `STATE_XXX_*.md` جدید ساخته می‌شود. فایل‌های قبلی **هرگز ویرایش نمی‌شوند.**

هر فایل state حاوی این موارد است:

- **کامیت** دقیقی که این وضعیت روی آن است؛ با `git checkout <commit>` می‌توان دقیقاً به همان کد برگشت
- خلاصه‌ای از معماری، تابع هزینه، داده و تنظیمات فعال
- آخرین نتایج و مشکلات شناخته‌شده
- وضعیت تست‌ها
- **تفاوت با state قبلی** (از STATE_001 به بعد)

## روش ساختن state جدید

1. کد را کامیت کنید.
2. آخرین فایل state را کپی کنید و شماره‌اش را یکی بیشتر کنید.
3. بخش‌های کامیت، تنظیمات، نتایج و مشکلات را به‌روز کنید.
4. بخش «تفاوت با state قبلی» را پر کنید. خروجی این دستور کمک می‌کند:
   `git diff --stat <commit قبلی> <commit جدید>`
5. یک ردیف به جدول بالا اضافه کنید.
