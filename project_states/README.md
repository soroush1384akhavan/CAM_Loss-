# روند تغییرات پروژه (Project States)

این پوشه یک «دفتر وضعیت» برای پروژه است. هر بار که پروژه یک قدم معنادار جلو می‌رود، یک فایل `STATE_XXX_*.md` جدید ساخته می‌شود و فایل‌های قبلی **هرگز ویرایش نمی‌شوند**.

هر state شامل این‌هاست:

- **commit** دقیقی که این وضعیت به آن اشاره می‌کند؛ با `git checkout <commit>` می‌شود دقیقاً به همان کد برگشت
- خلاصهٔ معماری، loss، داده و config فعال
- آخرین نتایج و مشکلات شناخته‌شده
- وضعیت تست‌ها
- **تفاوت با state قبلی** (از STATE_001 به بعد)

## روش ساختن state جدید

1. کد را commit کنید.
2. آخرین فایل state را کپی کنید و شمارهٔ آن را یکی بالا ببرید.
3. بخش‌های commit، config، نتایج و مشکلات را به‌روز کنید.
4. بخش «تفاوت با state قبلی» را پر کنید. خروجی این دستور به این کار کمک می‌کند:
   `git diff --stat <commit قبلی> <commit جدید>`
5. یک ردیف به جدول بالا اضافه کنید.
